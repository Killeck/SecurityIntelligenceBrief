# Release 5.6.8 — DEFCON scale and weekly vulnerability ordering

The Daily DEFCON legend again shows all five colour-coded levels in equal, email-safe boxes. The Weekly report places zero-days before Critical in its summary row and lists vulnerabilities in this order: zero-days, CVSS 10.0, unscored CVEs, then CVSS 9.9 through 4.0. Entries below CVSS 4.0 are omitted.
